# Wiki Minecraft

## Descrição

Site simples sobre Minecraft criado para demonstrar conhecimentos de HTML5.

## Autor

Igor Rafael

## Tecnologias

- HTML5

O projeto não utiliza CSS nem JavaScript.

## Como executar

Abra o arquivo `html/inicio.html` em um navegador.

## Estrutura

- `html/` — 11 páginas HTML do site.
- `img/` — imagens.
- `audio/` — áudio local.
- `video/` — vídeo local.
- `README.md` — documentação do projeto.
